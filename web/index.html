What it is

One small part, useful everywhere

Plain and honest: a bit-serial datapath that computes (a·b) mod m, in hardware, with no data-dependent branches. Small enough to understand, general enough to reuse.

01 · WHAT

Modular multiply

Multiplies two numbers and wraps them around a modulus — the inner loop of RSA, Diffie–Hellman, elliptic curves, and zero-knowledge proofs.

02 · WHY FIXED-TIME

No timing leak

Every multiply takes the same number of cycles regardless of the operands. The reduce/add choices are multiplexers, not branches — constant-time by construction.

03 · WHY HARDWARE

Guaranteed, not hoped

On a general CPU the compiler can silently break constant-time. A fixed-function datapath removes that whole class of side channel — by design.

Assurance · aerospace-grade

Simulated and proven

Testing shows it works for the cases you run. Formal verification proves it for every possible input. This core has both — and both are open-source, so you can re-run them yourself.

Compose · the interface is the contract

Wire it in — nothing bespoke

Two ways to use it: instantiate the core directly in your RTL, or drive the packaged accelerator over a 5-register MMIO interface from firmware. Same design, your choice of altitude.

// Drop the reusable core straight into your datapath
mulmod #(.WIDTH(32)) u_mul (
    .clk(clk), .rst_n(rst_n),
    .start(start),           // 1-cycle pulse
    .a(a), .b(b), .m(m),     // a < m, m > 0
    .result(result),         // (a·b) mod m, valid on `done`
    .done(done), .busy(busy) // fixed-latency handshake
);
OffsetRegisterMeaning
0x00CTRLSTART · RESET · LOAD_OP · LOAD_MOD
0x04STATUSBUSY · DONE · ERROR
0x08OPERANDoperand in
0x0CRESULTresult out
0x10MODULUSmodulus in
// Bare-metal Rust (no_std) — the packaged peripheral
let accel = BlindSigAccel::new(0x2000_0000);
let result = accel.compute(&[modulus], &[operand])?;   // reset → load → start → poll → read
