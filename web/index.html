blindsig · mulmod
a constant-time modular multiplier for risc-v — running live
the circuit github project

mulmod computes (a·b) mod m in hardware — one bit of b per clock, in a fixed number of cycles regardless of the operands. The fixed timing is the whole point: on a general-purpose CPU, secrets leak through how long the work takes; a fixed-function circuit cannot leak that way.

The circuit below is the real thing — mulmod.v compiled to WebAssembly with Verilator. The result, the accumulator and the cycle count are read straight from the running hardware, not re-implemented in JavaScript.

tested, and proved

Simulation shows it works for the cases you run; formal verification proves it for every input. Both live in the repository and re-run with an open toolchain:

git clone https://github.com/cong-or/blindsig-accel
cd blindsig-accel/blindsig-rtl
make          # simulate — unit test + accelerator (Icarus Verilog)
make formal   # prove     — k-induction + equivalence (SymbiYosys)
